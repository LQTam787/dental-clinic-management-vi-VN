┌─────────────────────────────────────────────────────────────────┐
│ DESKTOP SHORTCUTS (Recommended)                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  🛑 Shutdown Dental Clinic  →  Stops the system                 │
│  🔄 Restart Dental Clinic   →  Starts the system                │
│                                                                 │
│  Right-click both → Properties → Advanced →                     │
│  ✅ Check "Run as administrator"                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ HOW TO SHUTDOWN                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. Double-click "🛑 Shutdown Dental Clinic"                     │
│  2. Click "Yes" when Windows asks for admin rights              │
│  3. Wait for completion message                                 │
│  4. Press any key to close                                      │
│                                                                 │
│  ✅ System is now stopped - safe to maintain                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ HOW TO RESTART                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. Double-click "🔄 Restart Dental Clinic"                      │
│  2. Click "Yes" when Windows asks for admin rights              │
│  3. Wait 15-30 seconds for startup                              │
│  4. Window auto-closes when ready                               │
│                                                                 │
│  ✅ System is now running - test at http://localhost:8080        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ WHEN TO USE SHUTDOWN                                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  • Before updating the application                              │
│  • Before database maintenance                                  │
│  • When troubleshooting problems                                │
│  • Before changing configuration                                │
│  • Before restarting Windows                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ TYPICAL MAINTENANCE WORKFLOW                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 🛑 SHUTDOWN the system                                       │
│  2. 💾 BACKUP files (optional but recommended)                   │
│  3. 🔧 PERFORM maintenance (update, fix, configure)              │
│  4. 🔄 RESTART the system                                        │
│  5. ✅ VERIFY everything works                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Problem: "Must be run as Administrator"                        │
│  Fix: Right-click script → "Run as administrator"               │
│                                                                 │
│  Problem: Service won't start after restart                     │
│  Fix 1: Check database is running                               │
│  Fix 2: Check logs at C:\DentalClinic\service\logs\             │
│  Fix 3: Try manual start: java -jar [JAR file]                  │
│                                                                 │
│  Problem: Application not accessible after restart              │
│  Fix: Wait 30 more seconds, may still be starting               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ EMERGENCY: COMPLETE RESET                                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  If everything is broken:                                       │
│                                                                 │
│  1. Run shutdown script                                         │
│  2. Open Command Prompt as Admin                                │
│  3. Run: taskkill /F /IM java.exe                               │
│  4. Run: net stop postgresql-x64-14                             │
│  5. Run: net start postgresql-x64-14                            │
│  6. Run restart script                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
