## Key Things to Notice in the Output

### 1. Spring Boot Banner
The ASCII art banner confirms Spring Boot started successfully.

### 2. Hibernate DDL Statements
You see the actual `CREATE TABLE` statements that Hibernate generated from your entity classes:
- `create table patients (...)`
- `create table appointments (...)`
- `alter table ... add constraint fk_patient ...`

### 3. Data Insertion
After table creation, you see INSERT statements for the sample data from `data.sql`.

### 4. Test Output
The CommandLineRunner executes and prints:
- Clear section headers with `=` and `-` characters
- Test numbers and descriptions
- SQL queries generated by Hibernate (formatted)
- Results from each test
- Success message at the end

### 5. SQL Query Details
Notice how Hibernate formats the SQL:
- Proper indentation
- Alias usage (a1_0 for appointments, p1_0 for patients)
- WHERE clauses with parameter binding (`?` placeholders)
- JOIN syntax

### 6. Performance Insight
For TEST 2, notice there's only **ONE** SQL query to get all 6 appointments with patient data. This confirms the DTO pattern is working correctly and avoiding the N+1 problem!
