## Key Learnings from Tests

1. **DTO Pattern Effectiveness:**
   - Single JOIN query retrieves all needed data
   - No lazy loading issues
   - Prevents circular reference problems
   - Clean, flat structure for JSON serialization

2. **Flexible Filtering:**
   - NULL parameters completely ignored in WHERE clause
   - Can combine any number of filters
   - Search term applies to multiple fields (name OR phone)
   - Boolean filters support true/false/null

3. **JPQL Power:**
   - Database-agnostic queries
   - Entity-based (not table-based)
   - Constructor expressions for DTOs
   - Proper parameter binding prevents SQL injection

4. **Spring Data JPA Benefits:**
   - Automatic repository implementation
   - Built-in CRUD operations
   - Custom query support via @Query
   - Transaction management
